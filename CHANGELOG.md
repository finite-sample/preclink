# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Set the release version with `uv version X.Y.Z`, record the release here, and
tag the merged commit `vX.Y.Z`. Pushing the matching tag builds and publishes
that version.

## [Unreleased]

### Changed

- Adopted the py-canon fleet standard: `uv_build` backend with an explicit
  version, `src/` layout, reusable CI/docs/release workflows, ruff-only
  linting and pyright in place of mypy.
